# P- Relay to Express Switcher v1.0

Initial public release.

This macOS menu bar app helps switch between:

- Private Relay mode, where the ExpressVPN background daemon is disabled so iCloud Private Relay can work.
- ExpressVPN mode, where the ExpressVPN daemon is enabled and ExpressVPN is opened.

It is meant for people who have the issue where iCloud Private Relay stays unavailable even after ExpressVPN is closed because the ExpressVPN daemon is still running.

## Important

This does not make ExpressVPN and iCloud Private Relay run at the same time. It switches between them.

The app is unsigned and not notarized. On first launch, macOS may require right-clicking the app and choosing Open.
